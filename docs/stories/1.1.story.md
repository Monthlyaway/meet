# Story 1.1: Room Creation and Default Channel Setup

## Status
Done

## Story
**As a** meeting organizer,
**I want** to create a room with an automatic "Main Lobby" channel instead of directly joining a video conference,
**so that** I can later manage multiple team channels within the same room for better organization.

## Acceptance Criteria
1. Home page shows "Create Room" instead of "Start Meeting"
2. Room creation generates unique room ID and creates default "Main Lobby" channel
3. User automatically redirected to `/rooms/{roomId}/channels/main-lobby`
4. Room metadata stored with creator as admin
5. Existing `/rooms/{roomName}` URLs still work (backward compatibility)

### Admin Identity Management Strategy
[Source: team-channels-epic.md specifications]
```typescript
// Browser UUID System Implementation
class AdminIdentityManager {
  static getUserId(): string {
    let userId = localStorage.getItem('livekit-user-id');
    if (!userId) {
      userId = generateRoomId(); // Reuse existing randomString logic
      localStorage.setItem('livekit-user-id', userId);
    }
    return userId;
  }

  static async isRoomAdmin(roomId: string): Promise<boolean> {
    const userId = this.getUserId();
    const response = await fetch(`/api/rooms/${roomId}/metadata`);
    if (!response.ok) return false;
    const metadata = await response.json();
    return metadata?.adminUserId === userId;
  }
}
```
