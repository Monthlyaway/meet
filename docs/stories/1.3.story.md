**Core Workflows**: [Source: architecture/core-workflows.md]
- User Registration Flow: Form → POST /api/auth/register → Store JWT → Auto-login → Dashboard
- User Login Flow: Form → POST /api/auth/login → Store JWT → Dashboard
- Session Persistence: Check localStorage JWT on app load → Validate with backend
- Logout Flow: Clear localStorage → Clear auth state → Redirect to home

### Security Review

**CRITICAL SECURITY CONCERN IDENTIFIED:**

**JWT Token Storage in localStorage**
- **Risk**: Susceptible to XSS attacks where malicious scripts can access stored tokens
- **Impact**: Potential account takeover if XSS vulnerability exists elsewhere in application
- **Recommendation**: Consider using httpOnly cookies for token storage or implement additional XSS protections

**Security Strengths:**
- Proper token validation with backend on app initialization
- Automatic token cleanup on 401 responses
- Clean error handling prevents information leakage
- Password validation enforces minimum security requirements

### Performance Considerations
