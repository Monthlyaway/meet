
**Admin Identity Management:**
```typescript
class AdminIdentityManager {
  static getUserId(): string {
    let userId = localStorage.getItem('livekit-user-id');
    if (!userId) {
      userId = generateRoomId(); // Reuse existing randomString logic
      localStorage.setItem('livekit-user-id', userId);
    }
    return userId;
  }

  static async isRoomAdmin(roomId: string): Promise<boolean> {
    const userId = this.getUserId();
    const response = await fetch(`/api/rooms/${roomId}/metadata`);
    if (!response.ok) return false;
    const metadata = await response.json();
    return metadata?.adminUserId === userId;
  }
}
```

### API Specifications
[Source: team-channels-epic.md API implementation]

**Channel Management APIs:**
- **POST `/api/rooms/[roomId]/channels`**: Create new channel
  - Request Body: `{ displayName: string, creatorId: string }`
  - Response: `{ success: boolean, channel: Channel }`
- **GET `/api/rooms/[roomId]/channels`**: Fetch channel list
  - Response: `{ roomId: string, channels: Channel[] }`
- **DELETE `/api/rooms/[roomId]/channels/[channelId]`**: Delete channel
  - Response: `{ success: boolean }`

**Server-Sent Events API:**
- **GET `/api/rooms/[roomId]/events`**: Real-time updates
  - Event types: `CHANNELS_UPDATED`, `CHANNEL_DELETED`
  - Client connects via `EventSource` for real-time updates
